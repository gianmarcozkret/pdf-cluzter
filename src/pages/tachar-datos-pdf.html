Cómo tachar datos personales en un PDF

  1. Sube el PDF que quieres compartir.
  2. Marca qué datos buscar (DNI, RUC, celulares, correos) y agrega otras palabras si hace falta.
  3. Revisa la lista de datos encontrados y desmarca los que no quieras tachar.
  4. Pulsa «Tachar y descargar»: los datos se borran del archivo y quedan cubiertos en negro.

Preguntas frecuentes

¿El dato tachado se puede recuperar?

No. A diferencia de poner un rectángulo negro encima, esta herramienta elimina el texto del archivo: no se puede copiar, buscar ni recuperar.

¿Funciona con documentos escaneados?

Solo si el PDF tiene texto. Si es una foto o un escaneo, primero pásalo por la herramienta OCR para que tenga texto y luego táchalo.

¿Mi documento se sube a internet?

No. Todo se procesa dentro de tu navegador; el archivo nunca sale de tu dispositivo.
